# Reminder pentru Android

[Descarcă APK-ul Reminder](https://github.com/BTEC-Information-Technology/Reminder-Downloads/releases/latest/download/Reminder.apk)

Aplicație de remindere în limba română, cu alarme, recurențe și teme sezoniere. Funcționează offline, fără cont.

Necesită Android 8.0 sau mai nou. Versiunile publicate aici sunt pentru testare.

## Instalare

1. Deschide linkul de descărcare de pe telefon.
2. Deschide fișierul `Reminder.apk` descărcat.
3. Dacă Android cere, permite instalarea aplicațiilor din browserul sau managerul de fișiere folosit, apoi continuă instalarea.

Actualizările se instalează peste versiunea existentă, cu păstrarea taskurilor și setărilor.

[Toate versiunile și notele de publicare](https://github.com/BTEC-Information-Technology/Reminder-Downloads/releases)

Repository-ul găzduiește pagina de descărcare și versiunile APK. Codul sursă este administrat separat într-un repository privat.
